This project implements a signature verification system using MobileNetV2 as a feature extractor. It compares performance between CPU and GPU execution in Google Colab, measuring execution time and resource usage. The workflow includes:

Loading signature images from Google Drive

Extracting deep features with MobileNetV2

Comparing CPU vs GPU performance using execution time and CPU usage metrics

Visualizing results with bar charts

Verifying uploaded signatures against the dataset using cosine similarity

The system demonstrates how deep learning models can be applied to biometric verification tasks while highlighting the efficiency gains of GPU acceleration.
